# 历史时空舆图 · 高中历史互动学习系统

一个可直接用浏览器打开的**高中历史学习工具**：把中国历代疆域与同期世界政区放在同一张宣纸风地图上，配以世界史专题、知识库、自测、引文填空等模块。

> 面向《中外历史纲要（上/下）》与选择性必修教材范围，**非商业教育用途**。

---

## 功能

| 模块 | 说明 |
|---|---|
| 一、中外时空舆图 | 战国至民国 208 个时间相位的中国疆域连续形变；40 个权威年份的世界政区，可拖动时间轴逐年查看 |
| 二、城池沿革 | 71 座城池点选查看历代建置变迁 |
| 三、世界史专题 | 按《纲要下》九大单元组织的 9 个专题（要点 / 关键概念 / 与中国的关联） |
| 四、专题知识库 | 50 个中国史专题卡片 |
| 五、寻地挑战 | 看线索猜城池 |
| 六、自测小测 | 中国史 + 世界史混合选择题 |
| 七、引文填空 | 教材原文挖空 |
| 八、易错辨析 | 常见误区对比 |

**交互**：拖拽平移、滚轮/双指缩放、拖动时间轴、图层开关、搜索、键盘快捷键（← → 换朝、空格演绎、/ 搜索、Esc 关闭）。

**移动端**：已适配竖屏/横屏/iPad，触摸目标 ≥32px，朝代条与图层按钮横向滑动，顶部章节导航。

## 源码结构

```
index.html                 成品（单文件，约 22.4MB，含全部数据）
source/
  _v4_template.html        页面模板（HTML + CSS + JS 主体，约 126KB）
  _build_v4.py             构建脚本：把数据注入模板生成 index.html
  _extract_world_polities.py  世界政区数据提取（historical-basemaps → JSON）
  _enrich_world_history.py    世界史专题与大事年表生成
  _enrich_polity_info.py      世界政权简介库
```

### 重新构建

构建需要以下数据文件（因体积较大未入库，见下节）：

```
_jiangshan_data.json       中国疆域 208 相位（约 12.4MB）
_world_polities.json       世界政区 40 相位（约 5.9MB）
_world.json                世界史专题/大事/锚点
_v5_knowledge.json         专题知识库
_v6_cloze.json             引文填空题库
_v6_quiz.json              自测题库
_v6_pitfalls.json          易错辨析
_dl_world/world_relief.webp 地形底图（8192×4096）
```

构建命令：

```bash
python _build_v4.py
```

## 已知取舍

- **体积**：单文件 22.4MB，gzip 后约 6.9MB。为换取"离线双击即开、零依赖"，刻意把全部矢量数据内联。
- **精度**：中国疆域坐标保留 2 位小数（约 1.1km），世界政区 2 位小数（V14.6 起由 0.25° 简化改为 0.03°）。
- **性能**：拖动时间轴时用 `requestAnimationFrame` 合并重绘，实测快速拖动 30 次由 2842ms 降至 261ms。
